MailBrief Privacy Policy

Last updated: September 21, 2026

MailBrief is a Chrome extension that helps you understand Gmail message previews and prepare email drafts. This policy explains what the extension accesses and how information is handled.

Gmail access

When you connect Gmail, MailBrief uses Google’s read-only Gmail permission. It reads the mailbox address and limited message information needed for the features you request, such as sender, subject, date, labels, and short previews. MailBrief does not send, delete, archive, edit, or change Gmail messages.

AI processing

When you request a summary or draft, MailBrief sends the selected subjects and previews, your instructions, and any files you choose directly to Google Gemini using the API key you provide. This happens only after you request generation. Review Google’s Gemini API terms and privacy information for Google’s handling of that request.

Local storage

Your Gemini key, settings, cached results, and recent drafts are stored in the local Chrome profile. MailBrief does not operate a MailBrief cloud server for these items. You can remove the key, clear drafts, disconnect Gmail, or remove the extension from Chrome.

Sharing and security

MailBrief does not sell your information or send it to advertising companies. Gmail data is sent to Google only for the Gmail API request and to Google Gemini only when you request AI help. Keep your API key private and review generated text before using it.

Children and changes

MailBrief is not directed to children. We may update this policy when the extension changes; the latest version will be published on this page.
